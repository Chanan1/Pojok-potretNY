# 🤖 AGENTS.md — Rules for AI Coding

## 📌 General Rules

- Gunakan Next.js App Router
- Gunakan TypeScript
- Gunakan Tailwind CSS
- Gunakan functional components

---

## 🎨 UI Rules

- Gunakan layout:
  Left Sidebar + Center Preview + Right Panel

- Preview HARUS selalu:
  - center
  - ukuran dominan
  - responsive

- Gunakan design:
  - clean
  - minimal
  - aesthetic pastel

---

## 🧠 State Management

- Gunakan Zustand untuk global state
- Gunakan sessionStorage untuk session capture

---

## 📁 Naming Convention

- Components → PascalCase
- Variables → camelCase
- File → kebab-case

---

## 🧩 Component Rules

Gunakan reusable component:

- FramePreview
- CameraView
- EditorToolbar
- TemplateCard
- UploadDropzone

---

## ⚠️ Restrictions

- Jangan buat UI terlalu padat
- Jangan gunakan terlalu banyak warna
- Jangan ubah struktur layout utama

---

## 🎯 Goal

- UI harus terasa seperti:
  Canva / modern SaaS editor
- UX harus cepat & intuitif
